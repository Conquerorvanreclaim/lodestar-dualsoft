# CI credential material

This directory holds the credential files captured from the CI server of the Dualsoft (LODESTAR) estate.
Of the 30 credential files in that capture, the 12 OpenVPN profiles live in `../vpn/` and the remaining 18 are here (update-server access, kiosk / LUKS material, release keystore).
Values are reproduced verbatim, without redaction or rewriting.
Some of these secrets were still live at the time of publication.
